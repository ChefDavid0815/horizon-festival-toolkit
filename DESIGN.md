# Design

Recorded from the shipped 0.4 build (`src/register.css`, `src/ui.jsx`). Code is the authority; update this file when the system changes.

## World

The save is the car's official record, so the app looks like a Japanese vehicle register (車検証): pale security-tinted paper with a fine guilloche wave, dense boxed fields whose labels sit in a tab cut into the top-left border, sumi ink, and one vermilion hanko seal. It is an Operate surface. The world supplies type, palette, density and the seal. Navigation, tabs, inputs, selects and buttons are ordinary web controls.

## Type

- Display: Noto Serif SC 900 (page titles, sheet titles, seals, section names in the setup sheet). Self-hosted woff2 subsets generated by `scripts/build-fonts.cjs`.
- Body: Microsoft YaHei UI / Segoe UI, 13px base, 1.6 leading.
- Figures: Barlow Semi Condensed 500–700 with tabular numerals, for every value, PI, CR amount, car name and part ID.
- No eyebrows, no all-caps labels, no monospace.

## Components

- **Field** (`.field` + `.field-tab`): the core box. The label tab sits on the border. A staged field takes a vermilion border and tab.
- **Sheet** (`.sheet` + `.panel-tab`): a larger panel whose tab is filled with rail green.
- **Seal** (`<Seal>`): a wet seal (filled vermilion, stamped in with a 420ms scale-and-rotate) marks a staged change. A dry seal (outline) marks an archived record such as a backup. Glyphs: 改 staged, 控 backup, 返 restore snapshot, 印 the apply control.
- **Roll** (`<Roll>`): changed values re-enter digit by digit (26ms stagger) without moving the layout.
- **Tune track**: a 2px rail with quarter ticks. The ink mark is the current value. A staged value adds a vermilion ghost mark with a dot and a delta segment, and the output shows the struck old value beside the new one.
- **Reward meter**: point thresholds sit on a field's meter as small notches that fill green once reached. The reward cars are listed beneath it, with ✓ for cars already owned.
- **Dock**: a submission slip with staged counts per area and the seal button. The button stays inert grey until something is staged, then turns vermilion.
- **Rail navigation**: the active item becomes a paper tab joined to the workspace. Staged counts show as vermilion badges.

## Motion

- One page entrance: the scroll pane fades in and the page head rises 6px (380ms). The pane itself never moves, so its geometry stays exact.
- The seal stamp and the digit roll are the authored moments.
- Meters scale on `transform`.
- Tabs underline with `scaleX`.
- `prefers-reduced-motion` collapses all of it.

## Layout

- 236px rail (208px under 1360px), with the workspace scrolling inside its own pane.
- The window minimum is 1120×780.
- Radii: 3px for fields and sheets, 6px for buttons, full round only for seals and badges.
- Shadows always carry an offset and blur.
