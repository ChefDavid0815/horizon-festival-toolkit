# Horizon Festival Toolkit

Windows 季节赛存档工具，当前版本 0.1.1。项目在 `E:\Horizon Festival Toolkit`。

## 界面语言

首次启动跟随 Windows 首选系统语言：中文环境使用简体中文，其他语言使用 English。右上角可随时选择“简体中文”“English”或“跟随系统”；手动偏好写入应用自己的 settings.json，重启后保留。

## 本版本

- 查看 S1–S5，共 20 周的季节赛完成记录与积分。
- 可选择某周、整个赛季，或全选所有已识别的周。
- 写入之前保存原文件备份，修改加密存档时先做解密回读一致性校验。
- 同步处理已存在的 `C_ProfileData_SCopy`，恢复时分别还原两份原文件。
- **不包含加车功能。** 季节赛修改保持车库数据库的字节不变。
- 启动不会自动连接存档，不会自动修改或恢复任何存档。

## 使用

运行安装版或免安装版。先退出游戏，点击“连接存档”选择 `C_ProfileData`，然后选择需要的周。只有点击“备份并应用修改”才会写回所选文件。备份页可查看和恢复本工具产生的恢复点。

加密存档由随附的 ForzaCryptoTool 在线处理，会将所选文件传给 `forzamods.dev`。连接对话框会显示这一点；离线无法保证加密存档加解密可用。本工具不内置账号密码或私人 API 密钥。

## 适配范围与验证边界

目录从本机 FH6 2.440.853.0 的活动资源提取；只处理已识别的 FestivalPass v4 / schema 0x6efc7e34。未知布局会停止，不猜测二进制偏移。所选周的积分、活动完成记录、每日与每周分项和相应赛季统计会被更新。

本版本经过隔离副本的数据结构、选周范围、车库保持不变、幂等和备份恢复测试。**尚未验证游戏实际读档、所有卡片发亮、独立挑战子状态、奖励发放或线上同步结果。** 不把“字段写入成功”视为游戏内全部生效。加密服务不可用或改变协议也可能导致操作失败。

备份位置在 Windows 应用数据目录下的 `horizon-festival-toolkit\backups`，程序提供“打开备份目录”。卸载不删除备份。发生操作中断时，应先在备份页检查恢复点。

## 开发与验证

```
npm ci
npm run build
npm test
node scripts/verify-desktop.cjs
npm run package
```

测试使用已经存在于 `qa/cli-roundtrip.bin` 的私有样本；该文件不随安装包分发。桌面测试将其复制到独立的 `qa/desktop-*` 目录，限制文件操作在该目录内，既不扫描正式存档，也不向正式存档写入。没有测试样本时不能运行存档相关 QA。

`research` 和 `qa` 不随程序打包。界面参考 FH6 菜单的方形卡片、凝缩字体、荧光黄选中状态及品牌粉色，使用独立名称与图标。本工具与 Microsoft、Xbox、Playground Games 无隶属关系。
