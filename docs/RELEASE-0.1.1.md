# Festival Toolkit 0.1.1

Every week. A little brighter. / 每一周，都值得点亮。

A Windows x64 workshop for FH6 seasonal records, selected-week changes, backups and recovery. Five series, twenty recognised weeks, Simplified Chinese and English with system-language support.

FH6 季节赛存档工坊：S1–S5 共 20 周，按周选择，修改前备份，恢复原文件。中英文界面，可跟随系统并保存手动偏好。

- **Setup.exe**: installer / 安装版
- **Portable.exe**: portable application / 免安装版
- **SHA256SUMS-0.1.1.txt**: file verification / 文件校验

**Early release / 预发布：** unsigned Windows binaries. Encrypted saves are transmitted to `forzamods.dev` through the bundled upstream ForzaCryptoTool; network access is required. No car-adding feature. In-game loading, rewards and online synchronisation have not been verified. See the bilingual README before connecting a save.

Windows 程序未签名。加密存档需要通过随附工具上传至第三方服务处理。不包含加车；游戏读档、奖励、线上同步尚未验证。连接前请阅读 README 的数据流与适配说明。

Build and 12 core tests passed; existing desktop verification is documented separately. No player saves are included in source or release artifacts. / 构建与 12 项核心测试通过；既有桌面验证另有说明。源码与发布包不含玩家存档。
